### 1.2 K-04: metas guardadas al validar

**Lo que pasa hoy.** `semaphore` es guardado (`sgi_indicator.py:1039-1044`). Su cálculo efectivo es el de `SgiIndicatorMeasureTrajectory._compute_semaphore` (`sgi_indicator_trajectory.py:254-281`), que **no llama a `super()`** y lee `indicator.direction`, `range_*` e `indicator._sgi_targets_on(period_date)` (escalones). Sus dependencias incluyen `indicator_id.target_objective`, `target_acceptable`, `range_*` y `step_ids.*`. El candado de la validada (`_SGI_LOCKED_FIELDS`, `sgi_indicator.py:1317`) protege valor, periodo, indicador y estado, **no el semáforo**: cambiar la meta del indicador o corregir un escalón recolorea en la base cada medición validada. `target_objective`/`target_acceptable` de la medición son calculados no guardados (`sgi_indicator_trajectory.py:233-252`) y también cambian. El desglose (`sgi.indicator.measure.split`, `sgi_business_line.py:423-480`) tiene su propio semáforo guardado con `indicator._sgi_semaphore_on` y las mismas dependencias.

**Lo que se hace** (alternativa del reporte «congelar semáforo y metas al validar»; la otra, «exigir un escalón con fecha al cambiar la meta», queda fuera, P1):
- Campos guardados nuevos en la medición, de solo lectura y `copy=False`:
  - `sgi_targets_frozen` (Boolean, «Metas congeladas»), `sgi_frozen_date` (Date, «Congeladas el»);
  - `sgi_frozen_direction` (Char: `higher_better`, `lower_better` o `range`);
  - `sgi_frozen_objective`, `sgi_frozen_acceptable`, `sgi_frozen_range_min`, `sgi_frozen_range_max`, `sgi_frozen_range_tolerance` (Float, `digits=(16, 2)`).
- **Al pasar a validada** (cualquier vía: botón, lote, `write`, `create` con `state='validado'`, superusuario): después del `super().write`, `_sgi_freeze_targets()` guarda las metas del periodo (`indicator._sgi_targets_on(period_date)`, `direction`, `range_*`). Se escribe con `sudo()` y contexto `sgi_freeze=True`.
- **Semáforo:** override final de `_compute_semaphore` (`@api.depends` de los campos congelados; Odoo junta las dependencias de toda la cadena). Las congeladas que no estén pendientes ni sin dato se calculan con la función pura `sgi_semaphore(value, direction, obj, acc, lo, hi, tol)` sobre lo guardado; el resto va a `super()`.
- **Objetivo y aceptable de la medición** (`_compute_targets`): congeladas → lo guardado.
- **Desglose:** `SgiIndicatorMeasureSplit._compute_semaphore` usa las metas congeladas de su medición si las tiene.
- **Reabrir** (`state` sale de `validado`; solo MAST, por el candado existente): después del `write`, `sgi_targets_frozen=False` y nota en el chatter «Metas liberadas al reabrir (objetivo X, aceptable Y)». El semáforo vuelve a las metas actuales. Validar de nuevo congela las de ese momento.
- **Corregir el valor de una validada** (solo MAST o superusuario pueden, por el candado): el color se recalcula con las metas congeladas (P3).
- **Nadie escribe los campos congelados por RPC:** `write` rechaza `sgi_frozen_*`/`sgi_targets_frozen` sin el contexto `sgi_freeze` y sin `env.su` (`UserError`).
- **Aviso en el indicador:** al cambiar `target_objective`, `target_acceptable`, `direction` o `range_*` de un indicador con mediciones validadas, nota en su chatter: «N medición(es) validada(s) conservan las metas con las que se validaron».
- **Ficha de la medición:** grupo «Metas al validar» visible con `sgi_targets_frozen`, con los campos congelados (`range_*` solo si el sentido congelado es `range`).
- **Fuera:** las métricas de salud (57.99.0) no cambian; el «Rojo sin causa ni plan» y la NC por persistencia leen `semaphore`, que ya es estable. `sgi.business.line` (líneas de negocio) tiene otro semáforo sin validación: no aplica.

```python
# -*- coding: utf-8 -*-
"""57.100.0 (K-04, auditoría 2026-10): la medición validada guarda las metas
con las que se juzgó. Su semáforo, su objetivo y su desglose salen de ellas
aunque después cambie la meta del indicador o un escalón de la trayectoria.
Reabrirla (solo el Jefe MAST) las suelta; validarla otra vez las vuelve a
guardar."""
from markupsafe import Markup

from odoo import api, fields, models
from odoo.exceptions import UserError

from .sgi_calendar import sgi_today

FROZEN_FIELDS = ('sgi_targets_frozen', 'sgi_frozen_date', 'sgi_frozen_direction',
                 'sgi_frozen_objective', 'sgi_frozen_acceptable', 'sgi_frozen_range_min',
                 'sgi_frozen_range_max', 'sgi_frozen_range_tolerance')
TARGET_FIELDS = ('target_objective', 'target_acceptable', 'direction',
                 'range_min', 'range_max', 'range_tolerance')


def sgi_semaphore(value, direction, objective, acceptable, lo=0.0, hi=0.0, tol=0.0):
    """La misma regla que la medición y el desglose (trayectoria y rango)."""
    if direction == 'range':
        if lo <= value <= hi:
            return 'verde'
        return 'amarillo' if lo - tol <= value <= hi + tol else 'rojo'
    if direction == 'lower_better':
        return 'verde' if value <= objective else 'amarillo' if value <= acceptable else 'rojo'
    return 'verde' if value >= objective else 'amarillo' if value >= acceptable else 'rojo'


class SgiIndicatorMeasureIntegrity(models.Model):
    _inherit = 'sgi.indicator.measure'

    sgi_targets_frozen = fields.Boolean(
        string="Metas congeladas", readonly=True, copy=False, index=True,
        help="La medición está validada y conserva las metas con las que se validó: "
             "cambiar la meta del indicador no le cambia el color.")
    sgi_frozen_date = fields.Date(string="Congeladas el", readonly=True, copy=False)
    sgi_frozen_direction = fields.Char(string="Sentido al validar", readonly=True, copy=False)
    sgi_frozen_objective = fields.Float(string="Objetivo al validar", digits=(16, 2),
                                        readonly=True, copy=False)
    sgi_frozen_acceptable = fields.Float(string="Aceptable al validar", digits=(16, 2),
                                         readonly=True, copy=False)
    sgi_frozen_range_min = fields.Float(string="Mínimo al validar", digits=(16, 2),
                                        readonly=True, copy=False)
    sgi_frozen_range_max = fields.Float(string="Máximo al validar", digits=(16, 2),
                                        readonly=True, copy=False)
    sgi_frozen_range_tolerance = fields.Float(string="Tolerancia al validar", digits=(16, 2),
                                              readonly=True, copy=False)

    # ---- metas y semáforo ---------------------------------------------------
    def _sgi_frozen_semaphore(self):
        self.ensure_one()
        return sgi_semaphore(self.value, self.sgi_frozen_direction, self.sgi_frozen_objective,
                             self.sgi_frozen_acceptable, self.sgi_frozen_range_min,
                             self.sgi_frozen_range_max, self.sgi_frozen_range_tolerance)

    @api.depends('sgi_targets_frozen', 'sgi_frozen_objective', 'sgi_frozen_acceptable')
    def _compute_targets(self):
        frozen = self.filtered('sgi_targets_frozen')
        for measure in frozen:
            measure.target_objective = measure.sgi_frozen_objective
            measure.target_acceptable = measure.sgi_frozen_acceptable
        super(SgiIndicatorMeasureIntegrity, self - frozen)._compute_targets()

    @api.depends('sgi_targets_frozen', 'sgi_frozen_direction', 'sgi_frozen_objective',
                 'sgi_frozen_acceptable', 'sgi_frozen_range_min', 'sgi_frozen_range_max',
                 'sgi_frozen_range_tolerance')
    def _compute_semaphore(self):
        frozen = self.filtered(lambda m: m.sgi_targets_frozen
                               and m.state not in ('pendiente', 'sin_dato'))
        for measure in frozen:
            measure.semaphore = measure._sgi_frozen_semaphore()
        super(SgiIndicatorMeasureIntegrity, self - frozen)._compute_semaphore()

    # ---- congelar y soltar --------------------------------------------------
    def _sgi_targets_snapshot(self, when=None):
        self.ensure_one()
        indicator = self.indicator_id
        objective, acceptable = indicator._sgi_targets_on(self.period_date)
        return {
            'sgi_targets_frozen': True,
            'sgi_frozen_date': when or sgi_today(self.env),
            'sgi_frozen_direction': indicator.direction or 'higher_better',
            'sgi_frozen_objective': objective,
            'sgi_frozen_acceptable': acceptable,
            'sgi_frozen_range_min': indicator.range_min,
            'sgi_frozen_range_max': indicator.range_max,
            'sgi_frozen_range_tolerance': indicator.range_tolerance,
        }

    def _sgi_freeze_targets(self, when=None):
        for measure in self:
            measure.sudo().with_context(sgi_freeze=True).write(measure._sgi_targets_snapshot(when))
        return True

    def _sgi_thaw_targets(self):
        for measure in self.filtered('sgi_targets_frozen'):
            body = Markup("Metas liberadas al reabrir la medición (objetivo %s, aceptable %s).") % (
                measure.sgi_frozen_objective, measure.sgi_frozen_acceptable)
            measure.sudo().with_context(sgi_freeze=True).write(
                {'sgi_targets_frozen': False, 'sgi_frozen_date': False})
            measure.message_post(body=body)
        return True

    @api.model_create_multi
    def create(self, vals_list):
        for vals in vals_list:
            if set(vals) & set(FROZEN_FIELDS) and not self.env.su \
                    and not self.env.context.get('sgi_freeze'):
                raise UserError("Las metas congeladas las guarda el SGI al validar.")
        measures = super().create(vals_list)
        measures.filtered(lambda m: m.state == 'validado')._sgi_freeze_targets()
        return measures

    def write(self, vals):
        if set(vals) & set(FROZEN_FIELDS) and not self.env.context.get('sgi_freeze') \
                and not self.env.su:
            raise UserError("Las metas congeladas de una medición validada las guarda el "
                            "SGI al validar; no se editan a mano.")
        to_freeze = to_thaw = self.browse()
        if 'state' in vals:
            if vals['state'] == 'validado':
                to_freeze = self.filtered(lambda m: m.state != 'validado')
            else:
                to_thaw = self.filtered(lambda m: m.state == 'validado')
        res = super().write(vals)
        to_freeze._sgi_freeze_targets()
        to_thaw._sgi_thaw_targets()
        return res


class SgiIndicatorMeasureSplitIntegrity(models.Model):
    _inherit = 'sgi.indicator.measure.split'

    @api.depends('measure_id.sgi_targets_frozen', 'measure_id.sgi_frozen_objective',

                m.sgi_frozen_range_tolerance)
        super(SgiIndicatorMeasureSplitIntegrity, self - frozen)._compute_semaphore()
```

```python
import logging

from odoo import SUPERUSER_ID, api

_logger = logging.getLogger(__name__)


def migrate(cr, version):
    if not version:
        return
    env = api.Environment(cr, SUPERUSER_ID, {})
    Measure = env['sgi.indicator.measure'].with_context(active_test=False)
    todo = Measure.search([('state', '=', 'validado'), ('sgi_targets_frozen', '=', False)])
    before = {m.id: m.semaphore for m in todo}
    for measure in todo:
        measure._sgi_freeze_targets(when=measure.sgi_validated_date or None)
    env.flush_all()
    todo.invalidate_recordset(['semaphore'])
    changed = [m.id for m in todo if m.semaphore != before[m.id]]
    _logger.info("SGI 57.100.0 (K-04): %d medición(es) validada(s) con metas congeladas "
                 "(ids %s); %d cambiaron de color.", len(todo), todo.ids, len(changed))
    if changed:
        _logger.warning("SGI 57.100.0 (K-04): estas mediciones cambiaron de color al "
                        "congelar: %s. Revisar con el Jefe MAST.", changed)
```

```python
class HrEmployeeGrant(models.Model):
    _inherit = 'hr.employee'

    def _sgi_grant_skill(self, skill, level, date_from, date_to, origin,
                         channel=None, survey=None):
        """Crea, sube de nivel o renueva la competencia del empleado. Nunca baja
        de nivel ni acorta la vigencia. Devuelve 'nueva', 'subida', 'renovada' o
        False. Con 'nueva' o 'subida' abre la evaluación de eficacia."""
        self.ensure_one()
        if not (skill and level):
            return False
        Skill = self.env['hr.employee.skill'].sudo()
        current = Skill.search([('employee_id', '=', self.id), ('skill_id', '=', skill.id)],
                               order='valid_to desc nulls first, id desc', limit=1)
        result, record = False, current
        if not current:
            record = Skill.create({
                'employee_id': self.id, 'skill_id': skill.id,
                'skill_type_id': skill.skill_type_id.id, 'skill_level_id': level.id,
                'valid_from': date_from, 'valid_to': date_to or False})
            result = 'nueva'
        else:
            higher = level.level_progress > current.skill_level_id.level_progress
            longer = bool(current.valid_to) and (not date_to or date_to > current.valid_to)
            if not (higher or longer):
                return False
            vals = {'valid_to': date_to or False}
            if higher:
                vals['skill_level_id'] = level.id
            if skill.skill_type_id.is_certification:
                # Historia nativa de certificaciones: renglón nuevo (VERIFICAR 1.8-3).
                record = Skill.create(dict(vals, employee_id=self.id, skill_id=skill.id,
                                           skill_type_id=skill.skill_type_id.id,
                                           skill_level_id=vals.get('skill_level_id', current.skill_level_id.id),
                                           valid_from=date_from))
            else:
                current.write(vals)
            result = 'subida' if higher else 'renovada'
        if result in ('nueva', 'subida'):
            self.env['sgi.training.effectiveness'].sudo()._sgi_open(
                self, skill, level, date_from, origin, channel=channel, survey=survey)
        return result


class HrResumeLineSgi(models.Model):
    _inherit = 'hr.resume.line'

    @api.model_create_multi
    def create(self, vals_list):
        lines = super().create(vals_list)
        lines._sgi_grant_from_resume()
        return lines

    def _sgi_grant_from_resume(self):
        """Certificación aprobada o curso terminado → competencia. Cada línea en
        su savepoint: si algo falla, la línea nativa se queda y se avisa en el
        log (nunca tumba la entrega del examen ni el fin del curso)."""
        for line in self.sudo():
            source = line.survey_id if line.survey_id.sgi_skill_id else (
                line.channel_id if line.channel_id.sgi_skill_id else False)
            if not (source and line.employee_id):
                continue
            date_from = line.date_start or sgi_today(self.env)
            if line.survey_id:
                origin, date_to = 'examen', line.date_end or False
            else:
                months = line.channel_id.sgi_skill_validity_months
                origin = 'curso'
                date_to = date_from + relativedelta(months=months) if months else False
            try:
                with self.env.cr.savepoint():
                    line.employee_id._sgi_grant_skill(
                        source.sgi_skill_id, source.sgi_skill_level_id, date_from, date_to,
                        origin, channel=line.channel_id or None, survey=line.survey_id or None)
            except Exception as exc:  # noqa: BLE001 — la línea nativa no se pierde
                _logger.warning("SGI: no se otorgó la competencia de la línea de currículum %s "
                                "(%s); se reintenta con el cron de cursos.", line.id,
                                type(exc).__name__)
```

```python
class SgiTrainingEffectiveness(models.Model):
    """Eficacia de la capacitación (ISO 9001 7.2 c): a los 90 días de otorgar
    una competencia por examen o curso, su jefe dice si fue eficaz."""
    _name = 'sgi.training.effectiveness'
    _description = "Eficacia de la capacitación"
    _inherit = ['mail.thread', 'mail.activity.mixin']
    _order = 'due_date desc, id desc'
    _rec_name = 'skill_id'

    employee_id = fields.Many2one('hr.employee', string="Empleado", required=True,
                                  ondelete='restrict', index=True, readonly=True)
    company_id = fields.Many2one(related='employee_id.company_id', store=True, index=True)
    skill_id = fields.Many2one('hr.skill', string="Competencia", required=True,
                               ondelete='restrict', readonly=True)
    skill_level_id = fields.Many2one('hr.skill.level', string="Nivel", readonly=True)
    origin = fields.Selection([('curso', "Curso de eLearning"), ('examen', "Examen de certificación"),
                               ('manual', "Captura de RH")], string="Origen",
                              required=True, readonly=True)
    channel_id = fields.Many2one('slide.channel', string="Curso", readonly=True)
    survey_id = fields.Many2one('survey.survey', string="Examen", readonly=True)
    granted_date = fields.Date(string="Otorgada el", required=True, readonly=True)
    due_date = fields.Date(string="Evaluar a más tardar", required=True, index=True,
                           help="Día en que vence la evaluación de eficacia (90 días después).")
    evaluator_id = fields.Many2one('res.users', string="Evalúa", required=True, index=True,
                                   help="Jefe inmediato; si no tiene usuario, el responsable "
                                        "del departamento, RH o el Jefe MAST.")
    state = fields.Selection([('pendiente', "Pendiente"), ('eficaz', "Eficaz"),
                              ('no_eficaz', "No eficaz")], string="Resultado",
                             default='pendiente', required=True, tracking=True)
    result_note = fields.Text(string="Comentario", tracking=True,
                              help="Qué se observó en el trabajo. Obligatorio si no fue eficaz.")
    evaluated_date = fields.Date(string="Evaluada el", readonly=True)
    survey_input_id = fields.Many2one('survey.user_input', string="Encuesta al jefe",
                                      readonly=True)

    _employee_skill_date_uniq = models.Constraint(
        'unique(employee_id, skill_id, granted_date)',
        "Ya hay una evaluación de eficacia para esa competencia y fecha.")

    @api.model
    def _sgi_evaluator(self, employee):
        for user in (employee.parent_id.user_id, employee.department_id.manager_id.user_id):
            if user and user.active and not user.share:
                return user
        cron = self.env['sgi.cron']
        return self.env['res.users'].browse(cron._sgi_rh_user_id() or cron._sgi_manager_user_id())

    @api.model
    def _sgi_open(self, employee, skill, level, granted, origin, channel=None, survey=None):
        Param = self.env['ir.config_parameter'].sudo()
        days = int(Param.get_param(EFFECTIVENESS_DAYS_PARAM, '90') or 90)
        evaluator = self._sgi_evaluator(employee)
        existing = self.search([('employee_id', '=', employee.id), ('skill_id', '=', skill.id),
                                ('granted_date', '=', granted)], limit=1)
        if existing or not evaluator:
            return existing
        rec = self.create({
            'employee_id': employee.id, 'skill_id': skill.id, 'skill_level_id': level.id,
            'origin': origin, 'channel_id': channel.id if channel else False,
            'survey_id': survey.id if survey else False, 'granted_date': granted,
            'due_date': granted + timedelta(days=days), 'evaluator_id': evaluator.id})
        rec._sgi_invite_survey()
        self.env['sgi.cron']._sgi_schedule(
            rec, "Evaluar la eficacia de la capacitación: %s — %s" % (skill.name, employee.name),
            rec._sgi_activity_note(), evaluator.id, date_deadline=rec.due_date,
            key='eficacia_capacitacion:%d' % rec.id)
        return rec
```
