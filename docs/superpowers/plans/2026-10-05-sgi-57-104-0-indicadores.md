### 1.2 «Sin dato» en pantalla (B1)

Hoy `_compute_last_measure` (`sgi_indicator.py:241-252`) guarda `last_value = 0.0` cuando no hay medición capturada o validada, y las vistas pintan ese 0. `last_value` se queda como está (guardado, ordenable, lo usan `test_kpi20` y reportes); se agrega un **Char calculado sin guardar** que es lo que se muestra:

```python
# sgi_indicator.py, junto a last_semaphore (l.230)
sgi_last_value_label = fields.Char(
    string="Último valor", compute='_compute_sgi_last_value_label',
    help="Valor de la última medición con dato, con su unidad. «Sin dato» si "
         "ninguna medición tiene dato todavía (un 0 real sí se muestra).")

@api.depends('last_measure_id', 'last_value', 'uom')
def _compute_sgi_last_value_label(self):
    for indicator in self:
        indicator.sgi_last_value_label = indicator._sgi_value_text(
            indicator.last_value if indicator.last_measure_id else None)

def _sgi_value_text(self, value):
    """«95.2 %», «0 accidentes», o «Sin dato» si ``value`` es None."""
    self.ensure_one()
    if value is None:
        return "Sin dato"
    text = ('%.2f' % value).rstrip('0').rstrip('.') or '0'
    return ("%s %s" % (text, self.uom or '')).strip()
```

### 1.4 Capturar o validar una medición manual sin valor (B5)

Hoy `action_capture` (`sgi_indicator.py:1347`) escribe `capturado` sin revisar nada y `action_validate` (`:1350`) valida lo que haya; TI-01 jun–ago quedó validada en 0 sin numerador, denominador ni nota. Un `Float` no distingue «nadie escribió» de «escribieron 0», y el cliente web no manda un 0 que no cambió. Regla:

> Una medición de indicador **manual** con `value == 0`, sin numerador, sin denominador y **sin nota** no tiene valor capturado.

Para capturar un 0 de verdad, el responsable lo dice en la nota («0: sin caídas en el mes»). Sin campo nuevo ni respaldo de datos.

```python
# sgi_indicator_detail.py, clase SgiIndicatorMeasureDetail
def _sgi_without_value(self):
    """Mediciones manuales que no tienen valor capturado (B5, 57.104.0)."""
    return self.filtered(
        lambda m: m.indicator_id.calc_mode == 'manual' and not m.value
        and not m.numerator and not m.denominator and not (m.note or '').strip())

def _sgi_check_has_value(self):
    missing = self._sgi_without_value()
    if missing:
        raise UserError(
            "Capture el valor de %s antes de marcarla capturada o validarla. "
            "Si el valor de verdad es 0, escriba en la nota por qué (p. ej. «0: sin "
            "caídas en el mes»)." % ", ".join(missing.mapped('display_name')))
```

- `write` (en `SgiIndicatorMeasureDetail`, nuevo override; se suma a los de `sgi_indicator.py:1329` e `integrity`): si `vals.get('state') in ('capturado', 'validado')` y `not self.env.su`, revisa `self.filtered(lambda m: m.state != vals['state'])` **con los valores de `vals` aplicados** (si `vals` trae `value`/`note`, se revisa después del `super().write` dentro de un savepoint lógico: escribir primero y revisar después en la misma transacción; el `UserError` revierte todo). Implementación: `res = super().write(vals)` y luego `self._sgi_check_has_value()` sobre las que cambiaron de estado.

### 1.7 «Registro vacío» (B6)

Un 0 de «más bajo es mejor» pinta verde. Cuando la fuente nunca ha tenido un registro, ese verde es falso (SST-01: `sgi.incident` vacío; C5-01: ninguna reclamación con metros reclamados). No sirve «el numerador nunca ha tenido registros»: E2-01 (documentos con revisión vencida) en 0 es un dato bueno y real. Regla genérica, solo en `configurable` (el único modo donde el usuario arma la fuente):

> Si el indicador es «más bajo es mejor», el numerador da 0, y **algún término del numerador** tiene la fuente vacía, la medición queda **«Sin dato»** con la nota «Registro vacío: …». Fuente vacía = para «Contar» y «Contar donde B − A»: el **modelo** no tiene ningún registro (en la compañía de los KPI si el modelo tiene compañía); para «Sumar» y «Sumar el valor absoluto»: ningún registro del modelo (filtro del término sin ventana) tiene el campo sumado distinto de 0. «Promedio de B − A» ya da sin dato sin registros.

def _sgi_source_empty(self):
    """B6 (57.104.0): la fuente del término nunca ha tenido con qué medir."""
    self.ensure_one()
    Model = self.env[self.model_id.model].sudo().with_context(active_test=False)

    if self.aggregation in ('count', 'count_delta'):
        return not Model.search_count(company, limit=1)
    return False
