### 1.2 Tendencia del indicador (A1)

Hoy:
- `sgi_indicator.py:305-316` `action_view_trend` abre `sgi.indicator.measure` en `graph,list,form` con el dominio del indicador.
- `views/sgi_indicator_views.xml:508-518` `sgi_measure_view_graph`: línea, `period_date interval="month"`, `indicator_id`, `value type="measure"`.
- `value = fields.Float(...)` (`sgi_indicator.py:1033`) sin `aggregator`: en Odoo 19 un `Float` agrega con **suma** por omisión. Al agrupar por mes, las 4-5 semanales se suman (LO-01: 218 %). Además las mediciones **pendientes y sin dato** valen 0 y entran al grupo: en un mensual un mes «sin dato» sale como caída a 0.
- `target_objective` y `target_acceptable` de la medición son **calculados sin guardar** (`sgi_indicator_trajectory.py:233-236`, `sgi_indicator_integrity.py:84-91`): la gráfica nativa **no** los puede dibujar (solo agrega campos guardados).

**Decisión:**
- `value` lleva **`aggregator='avg'`** (en su definición, `sgi_indicator.py:1033`). Odoo no tiene agregador «último valor»; el promedio es el valor representativo del periodo y vale igual en pivote y lista agrupada (sumar valores de un indicador nunca tiene sentido). Una mensual agrupada por mes da su propio valor (promedio de uno).
- **Gráfica semanal** nueva `sgi_measure_view_graph_weekly` (misma arch con `interval="week"`); `action_view_trend` la usa cuando `frequency == 'weekly'` (`views` explícitas). No se depende de llaves de contexto de la gráfica (`graph_groupbys`), que no se pueden verificar sin Odoo.
- **Filtro «Con dato»** (`con_dato`: estado capturado o validado) en `sgi_measure_view_search` y `search_default_con_dato` en el contexto de la tendencia: los «sin dato» y pendientes no bajan la línea, y el usuario puede quitar el filtro. El dominio de la acción no cambia (la prueba `test_mywork.test_03` sigue igual).
- **Objetivo y aceptable:** en la lista de la tendencia (`sgi_measure_view_list`) se agrega `target_acceptable` junto a `target_objective` (ambos ya respetan metas guardadas y escalones). En la gráfica nativa no caben sin campos guardados nuevos (Q6); la **ficha PDF (C1)** los dibuja como franjas.

### 1.3 Pivote «Mapa de calor» de riesgos (A2)

Hoy `views/sgi_risk_views.xml:252-261`: filas proceso, columnas `attention_level`. `ATTENTION_LEVELS` (`sgi_risk.py:10-18`) mezcla las dos escalas (R&O/ambiental: baja, intermedia, media, inmediata; IPER/patrimonial: bajo, medio, alto): en producción el eje dice «Intermedia, Media, Medio, Alto» juntas.

**Decisión:** filas **instrumento → proceso**, columnas nivel:
```xml
<pivot string="Mapa de calor">
    <field name="instrument" type="row"/>
    <field name="process_id" type="row"/>
    <field name="attention_level" type="col"/>
</pivot>
```
Cada instrumento queda en su bloque de filas y solo llena las columnas de su escala; la escala doble es deliberada (comentario de `SGI_HIGH_ATTENTION`, `sgi_risk.py:20-25`), así que no se unifica. El mapa P×I de verdad es el PDF (C7).

"""57.101.0 (C1): ficha del indicador en PDF.

Una hoja por indicador: cómo se mide, metas, gráfica de los últimos periodos
con medición (SVG generado aquí; sin JS ni librerías) con las franjas verde /
amarilla / roja de CADA periodo, el semáforo guardado de cada medición y la
causa y acciones de los rojos. Las metas de un periodo son las que juzgaron
la medición: las guardadas al validar (K-04) o las vigentes del periodo
(escalón de trayectoria)."""
from markupsafe import Markup, escape

from odoo import models

SHEET_PERIODS = 12
SVG_W, SVG_H = 700, 250
PAD_L, PAD_R, PAD_T, PAD_B = 52, 10, 12, 36
POINT_COLOR = {'verde': '#198754', 'amarillo': '#cc9a06', 'rojo': '#dc3545'}
ZONE_COLOR = {'verde': '#d1e7dd', 'amarillo': '#fff3cd', 'rojo': '#f8d7da'}
INF = float('inf')


def sgi_zones(direction, objective, acceptable, lo=0.0, hi=0.0, tol=0.0):
    """Franjas (desde, hasta, color) de un periodo, con la regla de
    ``sgi_indicator_integrity.sgi_semaphore``."""
    if direction == 'range':
        return [(lo, hi, 'verde'), (lo - tol, lo, 'amarillo'), (hi, hi + tol, 'amarillo'),
                (-INF, lo - tol, 'rojo'), (hi + tol, INF, 'rojo')]
    if direction == 'lower_better':
        return [(-INF, objective, 'verde'), (objective, acceptable, 'amarillo'),
                (acceptable, INF, 'rojo')]
    return [(objective, INF, 'verde'), (acceptable, objective, 'amarillo'),
            (-INF, acceptable, 'rojo')]


def _num(value):
    return ('%.2f' % value).rstrip('0').rstrip('.')


def _bounds(values):
    lo, hi = min(values), max(values)
    if lo == hi:
        lo, hi = lo - 1, hi + 1
    pad = (hi - lo) * 0.08
    return lo - pad, hi + pad


def sgi_trend_svg(points, uom=''):
    """SVG (Markup) de la tendencia. ``points``: [{'label', 'value' (None =
    sin dato), 'semaphore', 'zones'}] en orden. Todo texto va escapado."""
    if not points:
        return Markup('')
    finite = [p['value'] for p in points if p['value'] is not None]
    finite += [b for p in points for z in p['zones'] for b in z[:2] if b not in (INF, -INF)]
    y0, y1 = _bounds(finite or [0.0])
    plot_w, plot_h = SVG_W - PAD_L - PAD_R, SVG_H - PAD_T - PAD_B
    slot = plot_w / len(points)

    def y(value):
        value = max(y0, min(y1, value))
        return PAD_T + plot_h * (y1 - value) / (y1 - y0)

    out = ['<svg xmlns="http://www.w3.org/2000/svg" width="%d" height="%d" '
           'viewBox="0 0 %d %d" font-family="Arial, sans-serif" font-size="9">'
           % (SVG_W, SVG_H, SVG_W, SVG_H)]
    for i, point in enumerate(points):           # franjas por periodo
        left = PAD_L + slot * i
        for lo, hi, color in point['zones']:
            top, bottom = y(min(hi, y1)), y(max(lo, y0))
            if bottom - top > 0.5:
                out.append('<rect x="%.1f" y="%.1f" width="%.1f" height="%.1f" fill="%s"/>'
                           % (left, top, slot, bottom - top, ZONE_COLOR[color]))
    for k in range(5):                           # eje y
        value = y0 + (y1 - y0) * k / 4
        out.append('<line x1="%d" x2="%d" y1="%.1f" y2="%.1f" stroke="#ccc" stroke-width="0.5"/>'
                   % (PAD_L, SVG_W - PAD_R, y(value), y(value)))
        out.append('<text x="%d" y="%.1f" text-anchor="end">%s</text>'
                   % (PAD_L - 4, y(value) + 3, escape(_num(value))))
    if uom:
        out.append('<text x="4" y="%d">%s</text>' % (PAD_T + 4, escape(uom)))
    segment = []                                 # línea: se corta en «sin dato»
    for i, point in enumerate(points + [{'value': None}]):
        if point.get('value') is None:
            if len(segment) > 1:
                out.append('<polyline fill="none" stroke="#333" stroke-width="1.5" points="%s"/>'
                           % " ".join(segment))
            segment = []
            continue
        segment.append('%.1f,%.1f' % (PAD_L + slot * (i + 0.5), y(point['value'])))
    for i, point in enumerate(points):           # puntos y etiquetas
        cx = PAD_L + slot * (i + 0.5)
        if point['value'] is None:
            out.append('<text x="%.1f" y="%.1f" text-anchor="middle" fill="#6c757d">s/d</text>'
                       % (cx, PAD_T + plot_h / 2))
        else:
            out.append('<circle cx="%.1f" cy="%.1f" r="3.5" fill="%s"/>'
                       % (cx, y(point['value']), POINT_COLOR.get(point['semaphore'], '#6c757d')))
        out.append('<text x="%.1f" y="%d" text-anchor="middle">%s</text>'
                   % (cx, SVG_H - PAD_B + 14, escape(point['label'])))
    out.append('</svg>')
    return Markup(''.join(out))


class SgiIndicatorSheet(models.Model):
    _inherit = 'sgi.indicator'

    def _sgi_period_label(self, period_date):
        self.ensure_one()
        if self.frequency == 'weekly':
            return "Sem %s" % period_date.strftime('%d/%m/%y')
        return period_date.strftime('%m/%Y')

    def _sgi_sheet_measures(self, limit=SHEET_PERIODS):
        """Las últimas ``limit`` mediciones del indicador, de la más vieja a
        la más nueva (los periodos medidos, no el calendario)."""
        self.ensure_one()
        return self.env['sgi.indicator.measure'].search(
            [('indicator_id', '=', self.id)], order='period_date desc', limit=limit,
        ).sorted('period_date')

    def _sgi_sheet_rows(self, limit=SHEET_PERIODS):
        self.ensure_one()
        rows = []
        for measure in self._sgi_sheet_measures(limit):
            direction, objective, acceptable, lo, hi, tol = measure._sgi_sheet_targets()
            has_value = measure.state in ('capturado', 'validado')
            rows.append({
                'measure': measure,
                'label': self._sgi_period_label(measure.period_date),
                'value': measure.value if has_value else None,
                'semaphore': measure.semaphore if has_value else False,
                'direction': direction, 'objective': objective, 'acceptable': acceptable,
                'range': (lo, hi, tol), 'frozen': measure.sgi_targets_frozen,
                'zones': sgi_zones(direction, objective, acceptable, lo, hi, tol),
                'red': has_value and measure.semaphore == 'rojo',
            })
        return rows

    def sgi_sheet_svg(self, rows=None):
        self.ensure_one()
        return sgi_trend_svg(rows if rows is not None else self._sgi_sheet_rows(), self.uom or '')

    def action_print_sheet(self):
        return self.env.ref('quimibond_sgi.action_report_indicator_sheet').report_action(self)

class SgiDiagramPrint(models.AbstractModel):
    _inherit = 'sgi.diagram'

    @api.model
    def data(self, kind, res_id=None, params=None):
        result = super().data(kind, res_id=res_id, params=params)
        result['print_report'] = kind in PRINT_KINDS and (
            kind == 'risk_matrix' or result.get('layout') in PRINT_LAYOUTS)

    @api.model
    def action_print_controlled(self, kind, res_id=None, params=None):
        """Acción del botón «Imprimir en formato controlado» de la barra del
        diagrama: el mismo diagrama en PDF con el pie del SGI."""
        if kind not in PRINT_KINDS:
            raise UserError("Este diagrama no tiene impresión en formato controlado; "
                            "use el botón de la impresora.")
        params = dict(params or {})
        res_id = int(res_id) if res_id else False
        if kind == 'risk_matrix':
            return self.env.ref('quimibond_sgi.action_report_risk_heatmap').report_action(
                None, data={'instrument': params.get('instrument') or 'ryo', 'process_id': res_id})
        return self.env.ref('quimibond_sgi.action_report_sgi_diagram').report_action(
            None, data={'kind': kind, 'res_id': res_id, 'params': params})

    @api.model

        """El subtítulo sin las instrucciones de pantalla (mouse, clic)."""
        parts = [p.strip() for p in (subtitle or '').split('·')]
        return " · ".join(p for p in parts if p and not any(h in p.lower() for h in SCREEN_HINTS))

    @api.model
    def _sgi_print_edges(self, dg):
        """[(de, qué, a)] de las flechas, con el nombre de cada caja."""
        names = {}
        for lane in dg.get('lanes') or []:
            for item in lane.get('items') or []:
                names[item['key']] = " ".join(x for x in (item.get('code'), item.get('name')) if x)
        matrix = dg.get('matrix') or {}
        for node in (matrix.get('rows') or []) + (matrix.get('cols') or []):

            if row[0] and row[2] and row not in seen:

class SgiAuditProgramPrint(models.Model):
    _inherit = 'sgi.audit.program'

    def _sgi_program_grid(self):
        """Programado contra realizado: una fila por (proceso o cliente /
        proveedor, tipo), 12 meses. Ejecutada = auditoría en «Informe» o
        «Cerrada» (la regla de SG-09), en el mes de su fin o inicio."""
        self.ensure_one()
        from .sgi_diagram_iso import MONTHS
        Line = self.env['sgi.audit.program.line']
        types = dict(Line._fields['audit_type'].selection)
        today = fields.Date.context_today(self)
        rows, findings, totals = {}, [], {m: {'planned': 0, 'done': 0} for m in range(1, 13)}
        for line in self.line_ids.sorted(lambda l: (l.process_id.code or l.partner_id.name or '',
                                                     int(l.planned_month))):
            key = (line.process_id.id, line.partner_id.id, line.audit_type)
            label = line.process_id.display_name or line.partner_id.display_name or types[line.audit_type]
            row = rows.setdefault(key, {
                'label': label, 'type': types[line.audit_type], 'auditors': [],
                'months': {m: {'planned': False, 'status': False, 'folios': []} for m in range(1, 13)}})
            planned = int(line.planned_month)
            audit = line.audit_id
            auditor = audit.lead_auditor_id or line.lead_auditor_id
            if auditor and auditor.name not in row['auditors']:
                row['auditors'].append(auditor.name)
            cell = row['months'][planned]
            cell['planned'] = True
            totals[planned]['planned'] += 1
            executed = bool(audit) and audit.state in ('informe', 'cerrada')
            if executed:
                when = audit.date_end or audit.date_start
                month = when.month if when and when.year == self.year else planned
                target = row['months'][month]
                target['status'] = 'cerrada' if audit.state == 'cerrada' else 'ejecutada'
                target['folios'].append(audit.folio or '')
                totals[month]['done'] += 1
                if month != planned:
                    cell['status'] = cell['status'] or 'movida'
                counts = Counter(audit.finding_ids.mapped('finding_type'))
                findings.append({'audit': audit, 'label': label, 'auditor': auditor.name or '',
                                 'counts': counts})
            elif date(self.year, planned, 1) < today.replace(day=1):
                cell['status'] = 'vencida'
            else:
                cell['status'] = 'pendiente'
        cutoff = 12 if self.year < today.year else (today.month if self.year == today.year else 0)
        internal = self.line_ids.filtered(lambda l: l.audit_type == 'interna')
        due = internal.filtered(lambda l: int(l.planned_month) <= cutoff)
        done = due.filtered(lambda l: l.audit_id.state in ('informe', 'cerrada'))
        start, end = date(self.year, 1, 1), date(self.year, 12, 31)
        outside = self.env['sgi.audit'].search([
            ('program_line_id', '=', False), ('date_start', '>=', start), ('date_start', '<=', end)])
        return {'months': MONTHS, 'rows': list(rows.values()), 'totals': totals,
                'findings': findings, 'outside': outside,
                'progress': (len(done), len(due))}

    def _sgi_heatmap_grid(self, instrument, scale, risks, p_field, i_field):
        levels = dict(ATTENTION_LEVELS)
        rows = []
        for impact in reversed(scale):
            cells = []
            for prob in scale:
                level = self._sgi_level(instrument, prob * impact)
                here = [r for r in risks if r[p_field] == str(prob) and r[i_field] == str(impact)]
                color = sgi_attention_color(level)

                              'color': color, 'bg': HEAT_BG[color],
                              'folios': [r.folio or str(r.id) for r in here]})
            rows.append({'impact': impact, 'cells': cells})
