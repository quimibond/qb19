# Glosario del SGI

Las palabras que verá en el menú **SGI** de Odoo y en los manuales, en una
línea cada una. Así se escriben en todas las pantallas.

| Término | Qué es |
|---|---|
| **SGI** | Sistema de Gestión Integral: calidad (ISO 9001), ambiente (ISO 14001) y seguridad y salud en el trabajo (ISO 45001). En Odoo es el menú **SGI** |
| **MAST** | El área de Medio Ambiente y Seguridad en el Trabajo, que también lleva el SGI |
| **Jefe MAST** | Quien administra el SGI: publica documentos, valida, da seguimiento a las NC y mantiene los manuales. En Odoo, el grupo **Jefe MAST y SGI** |
| **Dueño de proceso** | La persona responsable de un proceso (C4, E2…): es quien revisa sus actividades, indicadores y documentos y pide los cambios |
| **Proceso** | Un bloque del mapa de procesos: estratégicos (E), clave o de la cadena de valor (C) y de soporte (S) |
| **Actividad** | Un paso de un proceso: quién lo hace, cuándo vence, dónde se hace en Odoo y cómo se comprueba que se hizo |
| **Entregable** | Lo que una actividad recibe o entrega a otra (un reporte, una orden, un registro) |
| **MIID** | Manual de Información Documentada: el manual del sistema, generado desde Odoo |
| **MP (Mi procedimiento)** | Las actividades de su puesto, sus documentos y su EPP, en una pantalla que usted lee y firma |
| **NC (no conformidad)** | Algo que no cumplió lo establecido. Se registra, se analiza su causa y se corrige. En plural, «no conformidades» o «NC» |
| **CoA (certificado de calidad)** | El certificado que acompaña a un lote para el cliente |
| **IT (instructivo de trabajo)** | Documento que explica paso a paso cómo se hace una actividad. Clave IT-proceso-número, por ejemplo IT-C4-02 |
| **CO (control operacional)** | Documento que dice cómo se controla un aspecto ambiental o un riesgo de seguridad. Clave CO-proceso-número |
| **PROT (protocolo)** | Documento que dice cómo actuar ante una situación (por ejemplo, una emergencia). Clave PROT-proceso-número |
| **Reglamento** | Reglas que aplican a todos (por ejemplo, el reglamento de seguridad). Clave R-… |
| **Documento controlado** | Documento con clave, revisión y responsable, que solo cambia por el flujo de cambios documentales |
| **Revisión** | El número de versión de un documento controlado (00, 01, 02…). Cada revisión nueva pide releer y firmar |
| **Vigente** | La revisión que se usa hoy. Solo hay una vigente por clave |
| **Piloto** | Una revisión a prueba por un plazo corto, antes de quedar vigente |
| **Obsoleto** | Una revisión que ya no se usa; se conserva como evidencia |
| **Acuse de lectura** | Su firma de «leído y entendido» de un documento o de su procedimiento |
| **Indicador** | Una medición del desempeño de un proceso, con meta y semáforo |
| **Del Dropbox a Odoo** | La transición de los procedimientos y formatos del Dropbox a procesos y actividades en Odoo |
| **Conocimiento** | La app de Odoo donde están estos manuales y los instructivos, controles operacionales, protocolos y reglamentos para leer en pantalla |
